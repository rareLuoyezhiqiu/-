# 灵感清单 Demo

手机优先的单页交互原型，使用示例想法初始化，无后端、无账号。可新增、编辑、删除想法，恢复草稿。记录仅保存在当前浏览器，清理浏览器数据会丢失；不支持跨设备同步。

## 本地体验

安装 Node.js 后，在仓库目录运行：

```sh
npm install
npm run dev
```

浏览器打开 http://localhost:4173 。手机与电脑在同一局域网时，可打开 `http://电脑的局域网IP:4173`，需要电脑防火墙允许访问。不同设备的数据各自独立。

## 验证

```sh
npx playwright install chromium
npm test
```

测试覆盖新增、多段文字、空白校验、编辑排序、删除确认、刷新持久化、草稿恢复、存储失败重试、空状态和窄屏布局。测试过程截图位于 `test-results/`，整体界面截图位于 `artifacts/`。缩小视口模拟软键盘占用空间，真实手机键盘和添加到桌面需后续实机验证。
