# 灵感清单 0.2.0-alpha.1 · Android 预发布测试版

下载 Assets 中的 **inspiration-list-0.2.0-alpha.1.apk**，在安卓手机上安装即可使用基础记录功能。首次安装可能需要允许下载来源安装应用。

## 本版功能

- 新增、编辑、删除纯文字灵感，自动暂存编辑草稿。
- 原文与已保留拓写保存在手机应用内，断网仍可记录和回看。
- 在新增／编辑面板点击「帮我展开」或「保存并展开」，流式预览后手动保留。
- 在「API 设置」填写自己的服务商、完整 HTTPS 接口地址、模型和 API Key；手机直接调用接口，无需本项目的 Node 服务或个人访问口令。
- API Key 由 Android Keystore 中的系统密钥加密保存，不包含在 APK、JSON 备份或项目仓库中。调用费用由填写密钥的账户承担。
- JSON 导出调用系统文件保存界面，可自行选择保存位置。

## 安装与更新

- 要求 Android 7.0+，且系统 WebView 版本至少为 107。旧设备如提示 WebView 版本过低，请先更新系统 WebView。
- 下载 APK 安装即可，不需要部署服务器；仅 AI 拓写需要网络和有效的自备 API Key。
- 后续更新从本仓库 Releases 下载新 APK，直接覆盖安装。请勿为了更新先卸载，卸载或清除应用数据会删除本机记录。
- 浏览器版的数据不会自动进入 APK；本版提供导出，暂不支持导入或跨设备同步。
- `SHA256SUMS.txt` 提供 APK 校验值。

## 验证与已知边界

- 类型检查、网页构建、19 项协议/服务端测试、24 项浏览器测试通过。
- Android 15 / WebView 124 模拟器验证 Android Keystore 加密及重新读取、真实原生 HTTPS 分块响应、中文和 emoji、记录/草稿重开、返回键、离线、覆盖安装数据保留以及系统 JSON 文件保存。
- 原生 HTTPS 测试使用本机受控上游，不代表已用真实付费模型测试质量或中国大陆网络；使用前需填写有效密钥。
- 尚未完成实体安卓手机、多厂商系统和一周试用验证，因此本次为预发布测试版。遇到问题请在仓库 Issues 反馈，勿附 API Key 或私人灵感内容。
